# work_stuff

| Project | What it does |
|---|---|
| [sharepoint-digest](sharepoint-digest/) | Summarizes the PowerPoint and Word files in a SharePoint folder over a date range and rolls them up into a digest. Three versions: a local Python script for synced or downloaded folders, an online Python script that reads SharePoint directly (both using a GPT model in Azure AI Foundry), and a Copilot Studio agent built from topics. |
| [zeus-trial-of-olympus](zeus-trial-of-olympus/) | Zeus: Trial of Olympus — a 75-second Three.js arena survival game for Reddit (Devvit Web) with combo scoring, ultimate, Daily Trial and leaderboard. |
| [thor-trial-of-asgard](thor-trial-of-asgard/) | Thor: Trial of Asgard — a Norse retheme of the Zeus game: 75-second Three.js arena survival on Devvit Web where Thor smashes draugr, Fenrir wolves and frost giants with Mjölnir lightning, combos, Odinforce ultimate, Daily Trial and leaderboard. |
